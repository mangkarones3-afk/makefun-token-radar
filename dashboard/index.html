The model

For every tokenized protocol in the snapshot, the market's own multiple is mcap_usd / tvl_usd. In fitCategoryMultiples (lib/model.ts) each category's multiple is the median of its members' multiples, shrunk toward the global median in log space with weight n/(n+4): a category priced by 3 protocols leans on the global figure, one priced by 30 mostly stands on its own. Categories with fewer than 3 tokenized members use the global median outright. impliedValueUsd is then one multiplication — TVL × the category multiple — and multipleFor shows which figure each protocol received. No protocol name is hardcoded anywhere in the fit.

The fit runs on — tokenized protocols. — protocols record a market cap of exactly $0 in the snapshot and are excluded from the fit: a zero multiple carries no valuation signal. Tokenized and pre-token protocols are never mixed — the board holds only protocols that record no token (mcap, gecko id and symbol all null), and it draws the same product-type line the watchlist definition draws: wrapped, staked or bridged products of a token that already trades (WBTC is the snapshot notes' own example) are not launches waiting to happen, so bridge, liquid-staking and restaking product categories, exchange-fronted names and version-suffixed names sit aside. The board applies that line without the watchlist's $50M floor — the floor is a size line, the product-type line is a kind line, and only the kind line is kept. The trading set is a separate view.

The out-of-sample test

validateOutOfSample splits the fit set by slug order and holds out every third protocol (train —, held out —). The farm plans

Every board row carries a plan generated by farmSteps from the protocol's own facts: its category decides the line of work (supply-and-borrow cycles for lending, two-sided liquidity for a DEX, crossings in both directions for a bridge), its first chain decides the gas token and fee budget, and its TVL band decides the working capital and the number of weeks. Plans state costs and durations because a plan without them is a slogan. Steps are conditional where they must be — a protocol is only said to run a points programme if one is live on its official channels.

Words and limits

A protocol whose three token fields are null records no token in this snapshot. That is the strongest statement the file supports, and it is the phrase used throughout — the snapshot cannot prove a token does not exist, only that DefiLlama records none. The snapshot is frozen at —; nothing here is live data. Implied values inherit every limit of the multiple method: a category median cannot see team, unlocks, revenue or audits, and the wide out-of-sample error above is the honest size of that blindness.
